# Item Wise Report Automation

## Overview
A Python-based MIS reporting project for processing item-wise sales data and generating structured Excel reports.

## Technologies Used
- Python
- Pandas
- OpenPyXL

## Key Features
- Item-level data processing
- Sales data summarization
- Automated Excel report generation
- Structured and formatted report output

## Purpose
To simplify recurring item-wise MIS reporting and reduce repetitive manual work.

## Note
This is a portfolio project. No confidential company data is included.
