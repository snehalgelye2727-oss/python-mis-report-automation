# Python-Based Item-Wise Sales Report Automation

## Project Overview
This project automates item-wise sales analysis using Python, Pandas, and OpenPyXL. It transforms raw sales data into structured Excel reports to understand product performance across restaurant outlets and sales channels.

## Business Analysis
- **Category Analysis:** Summarizes quantity and sales amount across product categories.
- **Sales Contribution:** Calculates each category's percentage contribution to total sales.
- **Restaurant x Category Analysis:** Compares category-wise sales performance across restaurants.
- **Item Performance:** Identifies the Top 15 and Bottom 15 items based on sales amount.
- **Channel Analysis:** Compares offline, online, Zomato, and Swiggy sales at category and item levels.

## Key Features
- Category-wise quantity and revenue summary.
- Restaurant-wise category sales pivot.
- Top 15 and Bottom 15 item ranking.
- Sales contribution percentages.
- Conditional formatting and Excel charts.
- Raw data sheet.

## Tools Used
- Python
- Pandas
- OpenPyXL

## Output
Generates a formatted Excel workbook containing:
1. Category Summary & Restaurant x Category Pivot
2. Item Performance
3. Raw Data

## Conclusion
This automation helps evaluate product and category performance, identify high- and low-performing items, and compare sales across outlets and channels.
