# Sales Report Automation

## Overview
A Python-based project designed to automate recurring sales MIS reporting and generate structured Excel reports.

## Technologies Used
- Python
- Pandas
- OpenPyXL

## Key Features
- Data processing and cleaning using Pandas
- Restaurant-wise sales summaries
- Sales ranking and performance comparisons
- Automated Excel report generation
- Excel formatting and visualizations

## Purpose
To reduce repetitive manual reporting work and make sales data easier to analyze.

## Note
This repository is a portfolio implementation. It does not contain confidential company data or proprietary business information.
