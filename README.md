# Python-Based MIS Report Automation

A Python-based automation project designed to simplify MIS reporting through data processing, analysis, and structured Excel report generation.

## Reports Included

### 1. Sales Report
Analyzes outlet-wise sales performance, top and bottom outlets, and sales channel comparisons.

### 2. Item-Wise Report
Analyzes category-wise sales, item performance, and restaurant-level product trends.

### 3. Ewards Points Redeemed Report
Tracks outlet-wise loyalty points redemption, rankings, and total redeemed points.

## Tools & Technologies
- Python
- Pandas
- OpenPyXL
- Microsoft Excel
